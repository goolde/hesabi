# موقع منصة المحاسب الشامل

موقع ثابت (HTML + JavaScript) متصل بقاعدة بيانات وحسابات على Supabase.

## الملفات
- `index.html`: الموقع الرئيسي للطلاب والعملاء. فيه الإصدارات والأكاديمية والنماذج والوظائف وبوابة الطلبات، ودخوله مستقل.
- `admin.html`: بوابة الإدارة. لها دخول منفصل، ولا تفتح إلا لحساب دوره «إدارة».
- `assets/api.js`: **طبقة الاتصال الوحيدة بالخادم**. لو انتقلنا إلى خادم Python (FastAPI مثلاً) يُعاد كتابة هذا الملف وحده بنفس أسماء الدوال، ولا تتغير الواجهات.
- `assets/config.js`: عنوان الخادم والمفتاح العام. هذا المفتاح مصمم ليكون في المتصفح، والحماية الفعلية في صلاحيات قاعدة البيانات.
- `pages/` و`docs/` و`logos/`: صفحات العروض الفنية، وملفات PDF، والشعارات.

## الأدوار
| الدور | كيف يحصل عليه | ماذا يرى |
|---|---|---|
| طالب / عميل | التسجيل من الموقع | الأكاديمية، شهاداته، طلباته، نشر الوظائف، التنبيهات |
| مهندس صيانة | ترقية من الإدارة بعد التحقق | بوابة المهندسين |
| إدارة | ترقية من الإدارة | admin.html |

## النشر
يعمل على أي استضافة ملفات ثابتة: GitHub Pages أو Vercel أو Netlify أو استضافة الشركة.
1. ارفع محتوى هذا المجلد كما هو.
2. في Supabase افتح Authentication ← URL Configuration، واكتب رابط الموقع في Site URL وRedirect URLs. هذه الخطوة لازمة لتعمل رسائل التفعيل واستعادة كلمة المرور.
3. بريد التفعيل الافتراضي في Supabase محدود العدد. للإطلاق الرسمي أضف مزود بريد (SMTP) من Authentication ← Emails.
